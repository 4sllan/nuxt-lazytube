## Best Practices

Follow these recommendations to get the best performance and user experience with nuxt-lazytube.

## Accessibility

### Use Descriptive Titles

Always provide descriptive titles for accessibility and SEO:

```vue
<LazyYoutube 
  src="https://www.youtube.com/watch?v=VIDEO_ID"
  custom-title="Introduction to Vue.js Composition API - Complete Tutorial"
/>
```

Benefits:
- Screen readers can describe the video
- Better SEO
- Improved user experience

### Provide Context

Add surrounding content to describe the video:

```vue
<template>
  <article>
    <h2>Video Tutorial: Getting Started</h2>
    <p>This video covers the basics of using nuxt-lazytube.</p>
    <LazyYoutube 
      src="https://www.youtube.com/watch?v=VIDEO_ID"
      custom-title="Getting Started with Nuxt Lazytube"
    />
  </article>
</template>
```

## Performance

### Avoid Autoplay

Autoplay hurts performance and user experience:

```vue
<!-- Bad for performance -->
<LazyYoutube 
  src="https://www.youtube.com/watch?v=VIDEO_ID"
  :autoplay="true"
/>

<!-- Good for performance -->
<LazyYoutube 
  src="https://www.youtube.com/watch?v=VIDEO_ID"
/>
```

### Use Appropriate Thumbnail Quality

Choose thumbnail quality based on your needs:

```vue
<!-- For pages with many videos -->
<LazyYoutube 
  src="https://www.youtube.com/watch?v=VIDEO_ID"
  thumbnail-quality="medium"
/>

<!-- For featured videos -->
<LazyYoutube 
  src="https://www.youtube.com/watch?v=VIDEO_ID"
  thumbnail-quality="maxres"
/>
```

Quality guide:
- `default` - For pages with 10+ videos
- `medium` - For pages with 5-10 videos
- `high` - For pages with 2-5 videos
- `standard` - For featured videos
- `maxres` - For hero/featured videos

### Set Max Width

Limit video width to prevent layout issues:

```vue
<LazyYoutube 
  src="https://www.youtube.com/watch?v=VIDEO_ID"
  max-width="720px"
/>
```

Common widths:
- `560px` - Default, good for most cases
- `720px` - HD videos
- `1080px` - Full HD videos
- `100%` - Responsive full width

### Use Custom Thumbnails with Nuxt Image

Combine with Nuxt Image for optimized thumbnails:

```vue
<script setup>
const optimizedThumbnail = $img('/images/video-thumbnail.webp', {
  width: 640,
  height: 360,
  format: 'webp'
})
</script>

<template>
  <LazyYoutube 
    src="https://www.youtube.com/watch?v=VIDEO_ID"
    :custom-thumbnail="optimizedThumbnail"
  />
</template>
```

## Layout and Design

### Choose Appropriate Aspect Ratio

Match the aspect ratio to your video content:

```vue
<!-- Standard video -->
<LazyYoutube 
  src="https://www.youtube.com/watch?v=VIDEO_ID"
  aspect-ratio="16:9"
/>

<!-- Square video -->
<LazyYoutube 
  src="https://www.youtube.com/watch?v=VIDEO_ID"
  aspect-ratio="1:1"
/>

<!-- Cinematic video -->
<LazyYoutube 
  src="https://www.youtube.com/watch?v=VIDEO_ID"
  aspect-ratio="21:9"
/>
```

### Wrap in Container

Wrap videos in containers for better layout control:

```vue
<template>
  <div class="video-container">
    <LazyYoutube 
      src="https://www.youtube.com/watch?v=VIDEO_ID"
      max-width="100%"
    />
  </div>
</template>

<style scoped>
.video-container {
  margin: 2rem auto;
  max-width: 800px;
}
</style>
```

## User Experience

### Load Videos Only When Needed

Place videos below the fold or in tabs:

```vue
<template>
  <div>
    <h2>Video Tutorial</h2>
    <p>Read the documentation first, then watch the video.</p>
    
    <!-- Video below the fold -->
    <LazyYoutube 
      src="https://www.youtube.com/watch?v=VIDEO_ID"
    />
  </div>
</template>
```

### Provide Video Descriptions

Add descriptions to help users decide if they want to watch:

```vue
<template>
  <div>
    <h3>Advanced Features (15 min)</h3>
    <p>Learn about advanced features like custom thumbnails and player control.</p>
    <LazyYoutube 
      src="https://www.youtube.com/watch?v=VIDEO_ID"
      custom-title="Advanced Features Tutorial"
    />
  </div>
</template>
```

## SEO

### Add Structured Data

Add JSON-LD for video content:

```vue
<script setup>
useHead({
  script: [
    {
      type: 'application/ld+json',
      children: JSON.stringify({
        '@context': 'https://schema.org',
        '@type': 'VideoObject',
        name: 'Video Title',
        description: 'Video description',
        thumbnailUrl: 'https://example.com/thumbnail.jpg',
        uploadDate: '2024-01-01',
        embedUrl: 'https://www.youtube.com/embed/VIDEO_ID'
      })
    }
  ]
})
</script>
```

### Use Open Graph Tags

Add OG tags for social sharing:

```vue
<script setup>
useHead({
  meta: [
    { property: 'og:type', content: 'video.other' },
    { property: 'og:video', content: 'https://www.youtube.com/watch?v=VIDEO_ID' },
    { property: 'og:video:url', content: 'https://www.youtube.com/watch?v=VIDEO_ID' },
    { property: 'og:video:secure_url', content: 'https://www.youtube.com/watch?v=VIDEO_ID' },
    { property: 'og:image', content: 'https://example.com/thumbnail.jpg' }
  ]
})
</script>
```

## Error Handling

### Handle Invalid URLs

Provide fallback for invalid URLs:

```vue
<template>
  <LazyYoutube 
    :src="videoUrl"
    @error="handleError"
  />
</template>

<script setup>
const handleError = () => {
  console.error('Failed to load video');
  // Show error message or fallback
};
</script>
```

## Common Pitfalls

### Don't Use Too Many Videos

Avoid pages with too many videos:

```vue
<!-- Bad: 20 videos on one page -->
<div v-for="video in videos" :key="video.id">
  <LazyYoutube :src="video.url" />
</div>

<!-- Good: Pagination or lazy loading -->
<div v-for="video in visibleVideos" :key="video.id">
  <LazyYoutube :src="video.url" />
</div>
```

### Don't Ignore Mobile

Always test on mobile devices:

```vue
<!-- Good: Responsive width -->
<LazyYoutube 
  src="https://www.youtube.com/watch?v=VIDEO_ID"
  max-width="100%"
/>
```

### Don't Forget Accessibility

Always include titles and descriptions:

```vue
<!-- Good: Accessible -->
<LazyYoutube 
  src="https://www.youtube.com/watch?v=VIDEO_ID"
  custom-title="Descriptive title"
  show-title
/>
```
