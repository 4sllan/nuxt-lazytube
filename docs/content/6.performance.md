## Performance Impact

Nuxt Lazytube significantly improves page performance by deferring video player loading until user interaction.

## Traditional Iframe vs LazyTube

### Traditional Iframe

**What happens when you use a traditional iframe:**

1. **Page loads**
2. **Browser downloads YouTube/Vimeo player JavaScript** (typically ~1-2 MB depending on player version)
3. **Player initializes immediately**
4. **All videos on page load their players**
5. **User may never watch any of them**

**Impact:**

- ❌ Poor LCP (Largest Contentful Paint)
- ❌ High initial JavaScript payload
- ❌ Wasted bandwidth
- ❌ Slower Time to Interactive
- ❌ Higher memory usage

### Nuxt Lazytube

**What happens when you use Nuxt Lazytube:**

1. **Page loads**
2. **Browser downloads thumbnail images and video metadata** (typically ~10-50 KB per video for thumbnails, plus small metadata request, depending on thumbnail quality and caching)
3. **Lightweight placeholder displays**
4. **User clicks to play**
5. **Only then does the iframe load**

**Impact:**

- ✅ Excellent LCP
- ✅ Minimal initial JavaScript
- ✅ Bandwidth efficient
- ✅ Fast Time to Interactive
- ✅ Lower memory usage

## Real-World Example

Consider a page with **10 embedded videos**:

### Traditional Iframe

- **Initial Load**: ~10-20 MB of JavaScript (depending on number of videos and player version)
- **LCP Impact**: Significant delay
- **Memory Usage**: High
- **User Experience**: Slow initial load

### Nuxt Lazytube

- **Initial Load**: ~100-500 KB of thumbnails (depending on thumbnail quality and number of videos)
- **LCP Impact**: Minimal delay
- **Memory Usage**: Low
- **User Experience**: Fast initial load

**Result**: In illustrative scenarios with multiple videos, load times can be significantly faster (potentially 5-10x) with reduced memory usage. Actual results vary based on browser, network conditions, player version, caching, page structure, and thumbnail availability.

## Core Web Vitals Impact

### Largest Contentful Paint (LCP)

Traditional iframes often contain large video thumbnails and player code that contribute to LCP. Nuxt Lazytube:

- Loads only lightweight thumbnails
- Defers heavy player code
- Improves LCP score significantly

### Cumulative Layout Shift (CLS)

Nuxt Lazytube maintains consistent aspect ratios, preventing layout shifts when the iframe loads.

### Interaction to Next Paint (INP)

By reducing initial JavaScript payload, Nuxt Lazytube improves INP and Time to Interactive.

## Bandwidth Savings

For a page with 10 videos (illustrative example):

| Metric                     | Traditional Iframe | Nuxt Lazytube | Savings                   |
| -------------------------- | ------------------ | ------------- | ------------------------- |
| Initial Load               | ~10-20 MB          | ~0.5-1 MB     | **90-95%** (illustrative) |
| If User Watches 1 Video    | ~10-20 MB          | ~1.5-2 MB     | **85-90%** (illustrative) |
| If User Watches All Videos | ~10-20 MB          | ~10-20 MB     | 0%                        |

**Note**: These figures are illustrative examples. Actual bandwidth savings vary significantly based on browser, network conditions, player version, caching, page structure, and thumbnail availability. Most users don't watch all videos, so lazy loading typically saves bandwidth for the majority of users.

## Best Practices for Maximum Performance

### 1. Use Appropriate Thumbnail Quality

```vue
<LazyYoutube src="https://www.youtube.com/watch?v=VIDEO_ID" thumbnail-quality="medium" />
```

- `default` - Lowest quality (~10 KB)
- `medium` - Good balance (~30 KB)
- `high` - Higher quality (~50 KB)
- `standard` - Standard quality (~100 KB)
- `maxres` - Maximum quality (~200 KB)

### 2. Avoid Autoplay

```vue
<!-- Bad for performance -->
<LazyYoutube src="https://www.youtube.com/watch?v=VIDEO_ID" :autoplay="true" />

<!-- Good for performance -->
<LazyYoutube src="https://www.youtube.com/watch?v=VIDEO_ID" />
```

### 3. Set Max Width

```vue
<LazyYoutube src="https://www.youtube.com/watch?v=VIDEO_ID" max-width="720px" />
```

### 4. Use Custom Thumbnails When Possible

```vue
<LazyYoutube
  src="https://www.youtube.com/watch?v=VIDEO_ID"
  custom-thumbnail="/optimized-thumbnail.webp"
/>
```

Optimized WebP thumbnails can be even smaller than YouTube's thumbnails.
