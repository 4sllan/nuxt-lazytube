## Roadmap

This roadmap outlines planned features and improvements for nuxt-lazytube. Items are subject to change based on community feedback and priorities.

## Planned Features

### Video Platform Support

#### Loom

- Support for Loom video URLs
- Automatic thumbnail extraction
- Player customization options

#### Wistia

- Support for Wistia video URLs
- Automatic thumbnail extraction
- Player customization options

#### Bunny Stream

- Support for Bunny Stream URLs
- Integration with Bunny CDN
- Optimized streaming

#### Cloudflare Stream

- Support for Cloudflare Stream URLs
- Integration with Cloudflare CDN
- Adaptive bitrate streaming

#### Mux

- Support for Mux video URLs
- Integration with Mux platform
- Advanced analytics support

### Player Features

#### Player Events

- Enhanced event system
- More granular event tracking
- Custom event handlers
- Analytics integration

#### Programmatic API

- Extended player control API
- Volume control
- Playback speed control
- seeking functionality
- Fullscreen control

#### Playlist Support

- YouTube playlist support
- Vimeo album support
- Custom playlist creation
- Playlist navigation

#### Custom Thumbnails

- Local image support
- Dynamic thumbnail generation
- Thumbnail preview on hover
- Multiple thumbnail options

### SEO and Metadata

#### JSON-LD Automatic

- Automatic schema.org markup
- Video object structured data
- Enhanced SEO metadata
- Rich snippets support

#### Open Graph Tags

- Automatic OG tags generation
- Twitter card support
- Social media optimization

### Performance

#### Intersection Observer

- Advanced lazy loading with Intersection Observer
- Preload on viewport proximity
- Adaptive loading strategies

#### WebP Thumbnails

- WebP thumbnail support
- AVIF thumbnail support
- Automatic format selection

### Developer Experience

#### Nuxt 4 Enhancements

- Full Nuxt 4 compatibility
- Nuxt 4 specific optimizations
- New Nuxt 4 features integration

#### Composition API

- Enhanced Composition API support
- Composable functions
- Better TypeScript integration

#### DevTools Integration

- Nuxt DevTools integration
- Video inspector
- Performance monitoring

## In Discussion

These features are being discussed and may be added based on community interest:

- Video analytics integration
- A/B testing support
- Video chapter support
- Caption/subtitle support
- Multiple language support
- Accessibility enhancements
- Picture-in-picture support
- Background playback

## How to Contribute

Want to see a feature sooner? Here's how you can help:

1. **Vote on Issues** - React to GitHub issues to show interest
2. **Submit PRs** - Implement features and submit pull requests
3. **Provide Feedback** - Share your use cases and requirements
4. **Sponsor Development** - Support ongoing development

## Version Planning

### v0.3.0 (Next)

- Enhanced event system
- Player events
- Improved TypeScript types
- Bug fixes and performance improvements

### v0.4.0

- Loom support
- Wistia support
- Custom thumbnail enhancements
- JSON-LD automatic generation

### v1.0.0

- Additional platform support (Bunny, Cloudflare, Mux)
- Programmatic API
- Playlist support
- Full Nuxt 4 support

## Release Schedule

Releases are typically made every 4-6 weeks, depending on the scope of changes. Critical bug fixes may be released more frequently.
