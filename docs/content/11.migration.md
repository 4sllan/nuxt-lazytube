## Version 0.0.x → 0.1.x

### Breaking Changes

If you were using an early 0.0.x version:

1. **Component names changed** - Ensure you're using `<LazyYoutube>` and `<LazyVimeo>`
2. **Module configuration** - The module now auto-registers components

### Migration Steps

1. Update your imports if you were manually importing components:

```vue
<!-- Old way (0.0.x) -->
<script setup>
import LazyYoutube from 'nuxt-lazytube/components/LazyYoutube.vue'
</script>

<!-- New way (0.1.x) -->
<!-- Components are auto-imported, no import needed -->
```

2. Update your `nuxt.config.ts`:

```ts
// Old way (0.0.x)
export default defineNuxtConfig({
  modules: [
    ['nuxt-lazytube', {
      // options
    }]
  ]
})

// New way (0.1.x)
export default defineNuxtConfig({
  modules: ['nuxt-lazytube']
})
```

## General Upgrade Tips

### 1. Always Test After Upgrading

After upgrading, test your application to ensure:
- Videos load correctly
- Thumbnails display properly
- Custom configurations work as expected
- No console errors

### 2. Check the Changelog

Always review the [CHANGELOG.md](https://github.com/4sllan/nuxt-lazytube/blob/main/CHANGELOG.md) for detailed information about changes in each version.

### 3. Update Dependencies

When upgrading nuxt-lazytube, also ensure your Nuxt version is compatible:

```json
{
  "dependencies": {
    "nuxt": "^3.0.0",
    "nuxt-lazytube": "^0.2.0"
  }
}
```

### 4. Clear Cache

After upgrading, clear your Nuxt cache:

```bash
rm -rf .nuxt
rm -rf node_modules/.cache
```

## Troubleshooting

### Videos Not Loading After Upgrade

If videos don't load after upgrading:

1. Clear your cache
2. Restart your dev server
3. Check browser console for errors
4. Verify your URLs are still valid

### TypeScript Errors

If you encounter TypeScript errors:

1. Restart your TypeScript server
2. Clear your node_modules and reinstall
3. Check that your TypeScript version is compatible

### Build Errors

If you encounter build errors:

1. Clear your `.nuxt` directory
2. Clear your cache
3. Reinstall dependencies
4. Check for conflicting dependencies
