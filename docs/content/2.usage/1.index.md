After installing the module, you can start using the `<LazyYoutube>` and `<LazyVimeo>` components in your Nuxt application.

## Basic Usage

### YouTube Videos

::prose-pre
---

code: app.vue
filename: app.vue
---

```vue
<template>
  <LazyYoutube src="https://www.youtube.com/watch?v=TcMBFSGVi1c" />
</template>
```

::

### Vimeo Videos

::prose-pre
---

code: app.vue
filename: app.vue
---

```vue
<template>
  <LazyVimeo src="https://player.vimeo.com/video/64654583" />
</template>
```

::

## Supported URL Formats

Both components accept various URL formats:

- **YouTube**:
  - `https://www.youtube.com/watch?v=VIDEO_ID`
  - `https://youtu.be/VIDEO_ID`
  - `https://www.youtube.com/embed/VIDEO_ID`
  - `https://www.youtube.com/shorts/VIDEO_ID`

- **Vimeo**:
  - `https://vimeo.com/VIDEO_ID`
  - `https://player.vimeo.com/video/VIDEO_ID`

Any additional query parameters in the URL will be automatically included in the iframe.

### Programmatic Control

::prose-pre
---

code: app.vue
filename: app.vue
---

```vue
<script setup>
const lazyVideo = ref();

const play = () => lazyVideo.value?.playVideo();
const pause = () => lazyVideo.value?.pauseVideo();
const stop = () => lazyVideo.value?.stopVideo();
const reset = () => lazyVideo.value?.resetView();
</script>

<template>
  <div>
    <LazyYoutube 
      ref="lazyVideo" 
      src="https://www.youtube.com/watch?v=TcMBFSGVi1c" 
    />
    
    <div class="controls">
      <button @click="play">Play</button>
      <button @click="pause">Pause</button>
      <button @click="stop">Stop</button>
      <button @click="reset">Reset</button>
    </div>
  </div>
</template>
```

### With Events

::prose-pre
---

code: app.vue
filename: app.vue
---

```vue
<template>
  <LazyYoutube
    src="https://www.youtube.com/watch?v=TcMBFSGVi1c"
    @loaded="onLoaded"
    @playing="onPlaying"
    @paused="onPaused"
    @ended="onEnded"
  />
</template>

<script setup>
const onLoaded = (iframe) => {
  console.log('Video loaded', iframe);
};

const onPlaying = (videoId) => {
  console.log('Video playing', videoId);
};

const onPaused = (videoId) => {
  console.log('Video paused', videoId);
};

const onEnded = (videoId) => {
  console.log('Video ended', videoId);
};
</script>
```
