## Why Choose Nuxt Lazytube?

Nuxt Lazytube is a module for Nuxt that improves the performance of pages with videos by loading the iframe only when necessary.

## Benefits

🚀 **Better LCP** - Improves Largest Contentful Paint by deferring video player loading

⚡ **On-demand Loading (Lazy Loading)** - Videos load only when users interact with them

📦 **Native Nuxt Integration** - Built as a proper Nuxt module with auto-imports

🔥 **Zero Configuration** - Works out of the box with minimal setup

🎯 **Auto Imports** - Components are automatically available in your application

🧩 **TypeScript Support** - Full TypeScript support for better developer experience

🌐 **SSR Ready** - Works seamlessly with Server-Side Rendering

📺 **YouTube and Vimeo** - Support for both major video platforms

🎨 **Simple API** - Easy-to-use component-based API

📱 **Responsive** - Fully responsive video containers

## Performance Impact

For a page with 10 embedded videos:

- **Traditional iframe**: Loads ~11 MB of JavaScript immediately
- **Nuxt Lazytube**: Loads only ~100 KB of thumbnails initially
- **Result**: 7x faster load time and 2-3x less memory usage

## Why Not Traditional Iframes?

Traditional YouTube/Vimeo iframes load heavy JavaScript immediately when the page loads, even if the user never watches the video. This significantly impacts:

- **Core Web Vitals** - Especially LCP and CLS
- **Initial Load Time** - Multiple MB of unnecessary JavaScript
- **Mobile Performance** - Limited bandwidth is wasted
- **User Experience** - Slower page interactions

Nuxt Lazytube solves these problems by loading only a lightweight thumbnail initially, and replacing it with the actual iframe only when the user clicks to play.

## Why Not Other Libraries?

Unlike generic lazy loading libraries, Nuxt Lazytube is:

- **Built for Nuxt** - Native integration with Nuxt 3 and Nuxt 4
- **Auto-imported** - No manual component registration
- **Type-safe** - Full TypeScript support out of the box
- **SSR-compatible** - Works with static generation and server rendering
- **Zero-config** - No complex setup required
