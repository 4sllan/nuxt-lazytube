Nuxt Lazytube provides a comprehensive set of features for lazy loading YouTube and Vimeo videos in Nuxt applications.

| YouTube                   | ✅      |

| Auto Imports              | ✅      |
| TypeScript                | ✅      |
| Responsive                | ✅      |

## Platform Support

### YouTube

- Full support for all YouTube URL formats
- Automatic thumbnail extraction
- Custom thumbnail support
- YouTube Shorts support
- Playlist support (via URL parameters)

### Vimeo

- Full support for all Vimeo URL formats
- Automatic thumbnail extraction
- Custom thumbnail support
- Vimeo player options

## Performance Features

### Lazy Loading

- Loads only thumbnail initially
- Replaces with iframe on user interaction
- Reduces initial JavaScript load by ~1.1 MB per video
- Improves LCP (Largest Contentful Paint)

### SSR Compatible

- Works with Server-Side Rendering
- Compatible with Static Site Generation (SSG)
- No hydration issues
- Works with Nuxt 3 and Nuxt 4

## Developer Experience

### Auto Imports

- `<LazyYoutube>` component auto-imported
- `<LazyVimeo>` component auto-imported
- No manual component registration needed

### TypeScript

- Full TypeScript support
- Type-safe props
- Type-safe methods
- IntelliSense support

### Customization

- Custom play button via slots
- Custom loader via slots
- Custom thumbnails
- Custom titles
- Custom aspect ratios
- Custom iframe classes

## API Features

### URL Parsing

Automatic parsing of various URL formats:

- Standard watch URLs
- Short URLs (youtu.be)
- Embed URLs
- Shorts URLs
- Player URLs

### Player Control

Programmatic control via methods:

- `playVideo()` - Start playback
- `stopVideo()` - Stop and return to start
- `pauseVideo()` - Pause playback
- `resetView()` - Reset to initial state

### Props

Extensive prop support for customization:

- `src` - Video URL
- `aspectRatio` - Video aspect ratio
- `maxWidth` - Maximum container width
- `showTitle` - Display video title
- `autoplay` - Autoplay on load
- `thumbnailQuality` - Thumbnail quality
- `iframeClass` - Custom iframe class
- `customTitle` - Custom video title
- `customThumbnail` - Custom thumbnail URL
- `iframePolicy` - COEP iframe policy

## Security

### COEP Support

Support for Cross-Origin Embedder Policy (COEP) environments:

- `anonymous` policy
- `credentialless` policy

## Responsive Design

- Fully responsive video containers
- Maintains aspect ratio
- Configurable maximum width
- Works on all screen sizes
