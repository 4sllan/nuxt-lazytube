## Supported URL Formats

Nuxt Lazytube automatically parses and supports various URL formats for both YouTube and Vimeo. You can use any of the formats below - the module will handle the conversion automatically.

## YouTube URLs

### Standard Watch URL

```url
https://www.youtube.com/watch?v=VIDEO_ID
```

**Example:**

```vue
<LazyYoutube src="https://www.youtube.com/watch?v=TcMBFSGVi1c" />
```

### Short URL (youtu.be)

```url
https://youtu.be/VIDEO_ID
```

**Example:**

```vue
<LazyYoutube src="https://youtu.be/TcMBFSGVi1c" />
```

### Embed URL

```url
https://www.youtube.com/embed/VIDEO_ID
```

**Example:**

```vue
<LazyYoutube src="https://www.youtube.com/embed/TcMBFSGVi1c" />
```

### Shorts URL

```url
https://www.youtube.com/shorts/VIDEO_ID
```

**Example:**

```vue
<LazyYoutube src="https://www.youtube.com/shorts/TcMBFSGVi1c" />
```

### YouTube URLs with Parameters

Any additional query parameters are automatically preserved:

```url
https://www.youtube.com/watch?v=VIDEO_ID&t=30s&start=10
```

**Example:**

```vue
<LazyYoutube src="https://www.youtube.com/watch?v=TcMBFSGVi1c&t=30s" />
```

### YouTube Playlist URLs

Playlist URLs are supported via URL parameters:

```url
https://www.youtube.com/watch?v=VIDEO_ID&list=PLAYLIST_ID
```

**Example:**

```vue
<LazyYoutube
  src="https://www.youtube.com/watch?v=TcMBFSGVi1c&list=PLrAXtmErZgOeiKm4sgNOknGvNjby9efdf"
/>
```

## Vimeo URLs

### Standard Vimeo URL

```url
https://vimeo.com/VIDEO_ID
```

**Example:**

```vue
<LazyVimeo src="https://vimeo.com/64654583" />
```

### Player URL

```url
https://player.vimeo.com/video/VIDEO_ID
```

**Example:**

```vue
<LazyVimeo src="https://player.vimeo.com/video/64654583" />
```

### Vimeo URLs with Parameters

Any additional query parameters are automatically preserved:

```url
https://vimeo.com/VIDEO_ID?title=0&byline=0&portrait=0
```

**Example:**

```vue
<LazyVimeo src="https://vimeo.com/64654583?title=0&byline=0" />
```

## Complete URL Reference

### YouTube

| Format | Pattern                 | Example                                       |
| ------ | ----------------------- | --------------------------------------------- |
| Watch  | `youtube.com/watch?v=*` | `https://www.youtube.com/watch?v=TcMBFSGVi1c` |
| Short  | `youtu.be/*`            | `https://youtu.be/TcMBFSGVi1c`                |
| Embed  | `youtube.com/embed/*`   | `https://www.youtube.com/embed/TcMBFSGVi1c`   |
| Shorts | `youtube.com/shorts/*`  | `https://www.youtube.com/shorts/TcMBFSGVi1c`  |

### Vimeo

| Format   | Pattern                    | Example                                   |
| -------- | -------------------------- | ----------------------------------------- |
| Standard | `vimeo.com/*`              | `https://vimeo.com/64654583`              |
| Player   | `player.vimeo.com/video/*` | `https://player.vimeo.com/video/64654583` |

## Query Parameters

Any query parameters in the URL are automatically passed to the iframe. This allows you to control player behavior.

### YouTube Parameters

Common YouTube parameters:

- `t` or `start` - Start time
- `end` - End time
- `autoplay` - Autoplay (1 for yes, 0 for no)
- `controls` - Show controls (1 for yes, 0 for no)
- `loop` - Loop video (1 for yes, 0 for no)
- `playlist` - Playlist ID
- `list` - Playlist ID

**Example:**

```vue
<LazyYoutube src="https://www.youtube.com/watch?v=TcMBFSGVi1c&start=30&end=60&autoplay=1" />
```

### Vimeo Parameters

Common Vimeo parameters:

- `title` - Show title (1 for yes, 0 for no)
- `byline` - Show byline (1 for yes, 0 for no)
- `portrait` - Show portrait (1 for yes, 0 for no)
- `autoplay` - Autoplay (1 for yes, 0 for no)
- `loop` - Loop video (1 for yes, 0 for no)

**Example:**

```vue
<LazyVimeo src="https://vimeo.com/64654583?title=0&byline=0&portrait=0" />
```

## Best Practices

### 1. Use the URL You Have

Don't worry about converting URLs - use whatever format you have:

```vue
<!-- All of these work identically -->
<LazyYoutube src="https://www.youtube.com/watch?v=TcMBFSGVi1c" />
<LazyYoutube src="https://youtu.be/TcMBFSGVi1c" />
<LazyYoutube src="https://www.youtube.com/embed/TcMBFSGVi1c" />
```

### 2. Copy Directly from Browser

You can copy the URL directly from your browser's address bar:

```vue
<!-- Copy from YouTube.com -->
<LazyYoutube src="https://www.youtube.com/watch?v=TcMBFSGVi1c" />

<!-- Copy from Vimeo.com -->
<LazyVimeo src="https://vimeo.com/64654583" />
```

### 3. Use Short URLs for Cleaner Code

Short URLs are more readable in your code:

```vue
<!-- More readable -->
<LazyYoutube src="https://youtu.be/TcMBFSGVi1c" />

<!-- Less readable -->
<LazyYoutube src="https://www.youtube.com/watch?v=TcMBFSGVi1c" />
```

## URL Validation

The module automatically validates URLs and will:

- Extract the video ID correctly
- Preserve query parameters
- Handle both http and https protocols
- Ignore invalid URLs gracefully

If a URL is not recognized, the component will display an error message.

## Unsupported URLs

Currently, the following URLs are **not** supported:

- YouTube Live URLs
- YouTube Channel URLs
- YouTube User URLs
- Vimeo Groups
- Vimeo Albums
- Vimeo Showcase

These may be added in future versions based on demand.
