## Frequently Asked Questions

### General Questions

#### Does nuxt-lazytube work with SSR?

Yes, nuxt-lazytube is fully compatible with Server-Side Rendering (SSR) and Static Site Generation (SSG). The module works seamlessly with Nuxt 3 and Nuxt 4 rendering modes.

#### Does nuxt-lazytube work with Nuxt 4?

Yes, nuxt-lazytube is designed to work with both Nuxt 3 and Nuxt 4.

#### Does nuxt-lazytube work with Nitro?

Yes, nuxt-lazytube works with Nitro, the server engine used by Nuxt 3 and Nuxt 4.

#### Can I use nuxt-lazytube with SSG?

Yes, nuxt-lazytube works perfectly with Static Site Generation. The lazy loading functionality works client-side after the static site is deployed.

#### How do I use nuxt-lazytube with Nuxt Content?

You can use nuxt-lazytube components directly in your Markdown files when using Nuxt Content:

```markdown
---
title: My Article
---

# My Video Post

<LazyYoutube src="https://www.youtube.com/watch?v=VIDEO_ID" />
```

Make sure you have the MDC (Markdown Components) enabled in your Nuxt Content configuration.

#### Can I use private videos?

Yes, you can use private videos as long as:
- The video is accessible via the URL you provide
- You have the necessary permissions to view the video
- For YouTube, the video must be embeddable

For unlisted or private videos, ensure the embedding settings allow it.

#### How can I improve SEO with nuxt-lazytube?

To improve SEO:

1. **Use descriptive titles**:
   ```vue
   <LazyYoutube 
     src="https://www.youtube.com/watch?v=VIDEO_ID"
     custom-title="Descriptive video title for SEO"
   />
   ```

2. **Add alt text** (if using custom thumbnails):
   ```vue
   <LazyYoutube 
     src="https://www.youtube.com/watch?v=VIDEO_ID"
     custom-thumbnail="/video-thumbnail.jpg"
   />
   ```

3. **Include video descriptions** in your page content
4. **Use structured data** (JSON-LD) for video content
5. **Ensure fast page load** - lazy loading helps with this

### Performance Questions

#### Will lazy loading affect my Core Web Vitals?

No, lazy loading actually improves Core Web Vitals:
- **LCP** - Improves by deferring heavy video player loading
- **CLS** - Maintains stable layout with consistent aspect ratios
- **FID** - Improves by reducing initial JavaScript

#### How much bandwidth does lazy loading save?

For a page with 10 videos:
- **Traditional iframe**: ~11 MB initial load
- **Nuxt Lazytube**: ~0.5 MB initial load
- **Savings**: ~95% for users who don't watch videos

#### Does lazy loading work on mobile?

Yes, lazy loading works perfectly on mobile and is especially beneficial for:
- Limited bandwidth connections
- Slower mobile networks
- Battery life optimization
- Memory-constrained devices

### Technical Questions

#### What browsers are supported?

Nuxt Lazytube works with all modern browsers that support:
- ES6+ JavaScript
- HTML5 postMessage API
- CSS Grid/Flexbox

This includes:
- Chrome/Edge (latest)
- Firefox (latest)
- Safari (latest)
- Mobile browsers (iOS Safari, Chrome Mobile)

#### Can I customize the play button?

Yes, you can customize the play button using the `button` slot:

```vue
<LazyYoutube src="https://www.youtube.com/watch?v=VIDEO_ID">
  <template #button>
    <div class="custom-play-button">
      <Icon name="i-lucide-play" />
      <span>Watch Now</span>
    </div>
  </template>
</LazyYoutube>
```

#### Can I use custom thumbnails?

Yes, you can use custom thumbnails:

```vue
<LazyYoutube 
  src="https://www.youtube.com/watch?v=VIDEO_ID"
  custom-thumbnail="/images/my-thumbnail.webp"
/>
```

For best performance, use optimized WebP images.

#### How do I control the video programmatically?

You can use the exposed methods via refs:

```vue
<script setup>
const lazyVideo = ref();

const play = () => lazyVideo.value?.playVideo();
const pause = () => lazyVideo.value?.pauseVideo();
const stop = () => lazyVideo.value?.stopVideo();
const reset = () => lazyVideo.value?.resetView();
</script>

<template>
  <LazyYoutube ref="lazyVideo" src="https://www.youtube.com/watch?v=VIDEO_ID" />
  <button @click="play">Play</button>
  <button @click="pause">Pause</button>
</template>
```

#### What thumbnail qualities are available?

Available thumbnail qualities:
- `default` - Lowest quality (~10 KB)
- `medium` - Medium quality (~30 KB)
- `high` - High quality (~50 KB)
- `standard` - Standard quality (~100 KB)
- `maxres` - Maximum quality (~200 KB)

```vue
<LazyYoutube 
  src="https://www.youtube.com/watch?v=VIDEO_ID"
  thumbnail-quality="medium"
/>
```

### Troubleshooting

#### Video not loading?

If the video is not loading:
1. Check that the URL is valid and supported
2. Verify the video ID is correct
3. Check browser console for errors
4. Ensure the video is publicly accessible

#### Thumbnail not showing?

If the thumbnail is not showing:
1. Check the `thumbnail-quality` prop
2. Try a different thumbnail quality
3. Use a custom thumbnail if needed
4. Check browser console for errors

#### Aspect ratio wrong?

If the aspect ratio is incorrect:
```vue
<LazyYoutube 
  src="https://www.youtube.com/watch?v=VIDEO_ID"
  aspect-ratio="16:9"
/>
```

Common aspect ratios: `1:1`, `4:3`, `16:9`, `21:9`

#### Video not responsive?

If the video is not responsive:
1. Ensure parent container has width
2. Check the `max-width` prop
3. Verify CSS is not overriding styles

```vue
<LazyYoutube 
  src="https://www.youtube.com/watch?v=VIDEO_ID"
  max-width="100%"
/>
```
